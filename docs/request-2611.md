# 따님 수정 요청 (26.11.21 접수)

목표 : 친구들이랑 같이 하는 게임. 기본 그래픽 퀄리티를 크게 높이기(귀여운 3D, 원작 스타일).

## 공유 (멀티플레이)
- 링크로 들어온 사람끼리 같은 화면에 보임
- 새, 오리, 날씨, 나무, 열매 등 월드 전체가 모두에게 같게 보임
- 산책 시 친구 반려동물도 보임
- 모두 같이 자야 아침
- 채팅
- 친구 집 초인종 → 허락하면 방문

## 반려동물
- 종류 바꾸기(고양이 → 레서판다 등)
- 펫 가구 : 고양이 캣타워, 앵무새 새장, 레서판다/토끼 잔디 케이지, 강아지 개집, 나무늘보 작은 나무, 병아리 상자, 둥지. 들어가서 놀고 밤에 거기서 잠
- 여러 마리 키우기(같은 종 2마리는 혼자 불가)
- 모든 동물이 나와 충돌(통과 X)
- 산책 중 앵무새 더블탭 : 바닥에 내려와 따라옴 / 다시 더블탭 : 팔로 복귀
- 다른 펫, 까치, 참새도 더블탭으로 안고 다니기

## 길가
- 오리 : 날아오는 모습, 다가가면 연못 안에서 가장 먼 곳으로 이동, 혼자 또는 아기오리(최대 8) 동반, 여러 마리
- 까치 : 나무에 꽂히지 말고 가지에 착지해 앉는 모습, 혼자 또는 짝 따라다니기 → 둥지 → 알 1~3개 → 탭하면 알 들기 → 집 둥지에 두면 10분 뒤 부화, 아기까치는 작고 못 남, 15분 뒤 어른
- 집에 식물 + 까치 2마리 → 다시 알
- 참새 수와 출현 빈도 증가

## 집 기능
- 창문 열기, 커튼 닫기. 창문 열고 커튼 닫으면 집 까치가 밖으로 날아갈 수 있음
- 까치는 밥 불필요
- 창문 열면 바깥이 보임. 문 양쪽 + 각 벽마다 1개
- 창문 열고 외출하면 참새가 들어와 갇히기도 함 → 다시 창문 열면 날아감

## 미니게임
- 옆에 미니게임 버튼
- 미니야구 : 야구장, 베이스, 주자 1명씩, 투수 투구, 하단 "홈런" 버튼 타이밍
  - 좋은 타이밍 홈런, 그 외 안타/2루타, 못 치거나 너무 위/아래 = 아웃
  - 3아웃 종료, 홈런 = 타자 + 주자 수만큼 득점

## 식물 키우기
- 숲에 색 열매 나무(초록, 파랑, 하양, 노랑, 핑크, 보라 + 1색 = 7색), 딴 색은 5분 뒤 재생
- 열매 탭하면 들기 → 까치 탭하면 검정 부분만 열매색으로(흰 무늬 유지)
- 꾸미기에 작은 나무 : 새싹 → 물 몇 번 → 작은 나무. 까치 2마리면 둥지 틀고 알

## 교배
- 펫 : 친구의 같은 종과 교배 → 아기 2마리(알 또는 새끼), 각자 1마리씩, 20분 뒤 성장
- 까치 색 : 같은 색 = 같은 색, 노랑+초록 = 연두
  - 파랑/핑크/보라/검정 + 하양 = 하늘/연핑크/연보라/회색
  - 하늘 + 회색 = 청록, 청록 + 하양 = 민트

## 집 넓히기
- 집 안 상단 + 버튼 : 비닐하우스, 마당
- 마당 : 문 열어두기 가능 → 동물들이 마당에 나옴(밖으로는 못 나감, 사람만)
- 비닐하우스 : 집 옆, 식물/둥지/펫 집 배치, 데려온 동물 번식, 넓게 키우기

## 날씨 (모두에게 같게)
- 흐림, 비, 맑음, 아주 가끔 눈
- 비 : 길가 새가 창문으로 집에 피신하거나 나무 밑에 숨음
- 밤 : 길가 새와 오리 안 보임(집 새는 예외)

## 확정 사항 (26.11.21 DG님, 따님 답변)
- 열매 7번째 색 : 빨강 (초록, 파랑, 하양, 노랑, 핑크, 보라, 빨강)
- 같은 종 2마리 금지 규칙 : 까치는 예외. 다른 동물은 교배 아기를 데려올 때 엄마/아빠 중 한 마리를 친구에게 보내거나 놓아줌
- 정의 안 된 까치 색 조합 : 부모 색 중 하나 랜덤
- 집 까치는 창문과 커튼이 둘 다 열려 있을 때만 날아감
- 이름 붙인 까치는 날아가도 가끔 창가로 돌아옴
- 밤은 최대 5분, 접속자 모두 자면 즉시 아침
- 비 피신 : 창문 열린 집 중 가까운 집
- 미니야구 : 실제 야구처럼 주자 밀어내기 득점, 3루타 없음 (홈런, 2루타, 안타, 아웃)
- 그래픽 : 둥글고 말랑한 원작 스타일(툰 셰이딩, 윤곽선, 그림자, 그라데이션 하늘, 구름), 저사양 옵션
- 공유 월드 : Firebase 무료 플랜, 날씨/새/오리/열매는 시간+고정 시드로 각 폰이 계산, 행동(알 줍기, 열매 따기 등)만 서버 기록
- 창밖 : 그림 배경 + 창가에 새가 날아와 앉는 정도
- 교배, 초인종 : 상대 오프라인이면 요청 남기고 나중에 수락
- 채팅 안전 : 초대 코드 입장, 닉네임만, 욕설 필터, 개인정보 입력 없음, 방장 내보내기
- 성능 상한 : 연못 오리 최대 3가족, 참새 근처 10마리 정도
